# DARK HUNTER Android Gaming Panel

A simple native Android demo UI with a red/black neon theme, local demo login, draggable quick panel, and visual tool cards. It does not connect to or modify Free Fire.

## Build an APK on a computer
1. Install Android Studio.
2. Open this folder as an existing project.
3. Let Gradle sync. Use JDK 17 if prompted.
4. Select Build > Build APK(s).
5. Find the APK in `app/build/outputs/apk/debug/`.

## If you only have an Android phone
Android Studio is desktop software. You can keep this ZIP and open it on a computer later, or use a reputable Android IDE/build service that supports Gradle Android projects. Avoid uploading private credentials to unknown build sites.

## Demo login
Enter any non-empty username and password. This is only a local UI demonstration; it does not authenticate or store credentials.

## Notes
- Min Android version: Android 6.0 (API 23)
- Package: `com.darkhunter.panel`
- No internet permission or external libraries required.
